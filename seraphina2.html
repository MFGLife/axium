The Architecture

LAYER 01

Ephemeris Engine

Real-time calculation of planetary positions, aspects, house placements, and orbital mechanics. Swiss Ephemeris accuracy without the bloat.

LAYER 02

Temporal Gates

Eight-phase cycle mapping (Midnight to Night) determining action posture. Not "good/bad" but "build/wait/bury/inspect."

LAYER 03

Constraint Topology

Ten Axiums as interpretive filters. Each planet activates specific drift-detection protocols (Sun=Source, Saturn=Friction, etc.).

THE RAG METHODOLOGY

Retrieval Strategy Queries are vectorized by celestial state (planet positions ±2° orbs, house activations, aspect patterns). Retrieved historical interpretations weighted by Gate appropriateness and Axium constraint matching.
Generation Protocol LLM generates interpretation through Seraphina's constraint layer— no deterministic predictions, only feedback loops, tradeoffs, and single recommended actions timed to current Gate.
